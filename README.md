# End-to-end-autonomous-driving-framework:
1.	Orion- It combines vision, language models, and trajectory planning
2.	THOR- a next generation AI computing module designed for robotics, humanoids, and advanced autonomous systems
3.	VAD (Vectorized Autonomous Driving)- vectorized scene representation for faster, safer planning
4.	OpenEMMA — open source multimodal E2E driving with transparent planning
5.	SparseDrive — sparse scene representation for safer, faster E2E driving
6.	Hydra MDP (NVIDIA) — multi teacher distillation framework; CVPR 2024 winner.
7.	CoReVLA — dual stage E2E driving for long tail scenarios using VLMs + DPO.
